# Writing-DNA

> 海外仿真人短剧剧本（投稿找小黑语料库）写作 DNA 整合文档。语料：80 份文档 / 约 65 部剧 / 3420 集 / 55,492 行英文台词。使用本 DNA 写作前，须先读完全部四份分层产物，再从 `raw/` 选 5 部与目标体裁最近的剧本通读校准语感。

## 一句话定位

为欧美/拉美/东南亚竖屏短剧平台（ReelShort/DramaBox 系）写**付费驱动的分集剧本**：单集 1.5-2 分钟、全剧 30-60 集，文本形态为"中文场记 + ▲ 动作行 + 英文台词带中文对照 +【字幕】【特效】标记"的四层工程文档。

## 语言特征（L1）

- 英文台词平均 **5.5 词/句**，≤5 词短句占 59%；一句话一个情绪点，对白回合制"攻击—反击—升级"。问句+感叹句约占 1/3。
- 高频功能句型直接复用：羞辱 `How dare you…`、反转宣言 `I'm the one who…`、誓言 `You'll never…`、占有 `You're mine.`、悬念 `Wait—` / `What did you just say?`
- 每个赛道先撒术语群：狼人 alpha/luna/pack/mate/omega；霸总 contract/billion/CEO；奇幻 magic/majesty/blood。
- VO（内心独白）女频占台词 10-30%、虐恋/擦边可达 60%，男频 <10%。VO 三功能：开场定人设、转场补信息、集尾点题。
- 中文动作行 15-35 字、一句一个镜头，情绪全部写成可视化表情指令（瞳孔收缩、死死攥紧、冷笑）。
- 铁格式：`角色(情绪): "English line."（中文对照。）`；中文对照比英文更口语、可增译情绪。数字（金额/年份/年龄）必须具体并进台词。

## 结构模板（L2）

**单集**：场记行 → 开场镜头直接承上集悬念 → 冲突回合 1 → 动作转折 → 冲突回合 2 → 集尾钩（定格/黑场/闪白 + 中断台词 + 未完待续字幕）。每集 2.2 场、约 20 行台词、只推进一个冲突单元，集尾钩不可省。

**第 1 集四层钩**：前 3 秒视觉钩（反常画面不解释）→ 前 30 秒信息钩（身份反差+利害+威胁三连）→ 前 60 秒金钩（亮全剧底牌）→ 集尾痛点钩（锁定核心冲突）。开局骨架二选一：冷开场闪回式（先演结局级危机再"X 年前"）或 VO 自我介绍式（三句定人设）。

**全剧（50 集基准）**：付费墙设 EP5/12/24/38/45，每个墙必须 ≥9/10 大情绪点；卡点密度低开高走、每 5 集一个台阶；情绪 5 段式：隐忍→蒙冤→觉醒→翻盘→收束。

**分型骨架**：女频虐恋=辜负→觉醒→离开→追妻火葬场→加冕；男频=主动放弃既得利益→被欺压→底牌层揭→当众打脸→登顶；18+=封闭空间+禁忌身份+蒙在鼓里的第三方，按"铺垫—接触—升级—险被撞破—蒙混"循环，亲密层级逐段解锁；校园=秘密→暴露→霸凌维护→双向奔赴。

**拆剧文档**：基础信息 → 四层钩拆解 → 付费墙表+卡点曲线 → 人物弧线（起点/转折/高潮/终点）→ 换皮方法论（换赛道/姊妹剧/换体量/三关）→ 集纲（大期待/框架/核心梗+前 10 集逐集）。每个判断标出处，实证与推断分级。

## 选题判断标准（L3）

- 只写榜单已验证的赛道（女频为主力：婚恋/狼人/重生复仇/校园/霸总；男频做扮猪吃老虎）；立项依据引用平台周榜。
- 单剧 = 2-4 个成熟母题复合（如重生+调包+隐藏身份），不做无叠加的平铺故事，不追无人验证的新题材。
- 先问"付费墙设在哪几集"，再问故事；说不出付费墙落点的题材不写。
- 红线：不碰直系血亲禁忌、未成年性暗示；18+ 是底线。
- 换皮三关自检：骨架有硬支撑 / 物件钩可挪用、人物关系可变体 / 文化符号贴合本地中产认知（北美集团+品牌，拉美农场+教堂，东南亚企业+寺庙）。

## 素材使用规范（L4）

- 一手素材 = 成片转写；没看过成片只凭梗概的题材不写。
- 可信度靠符号密度不靠考据：具体金额（$2 million）、品牌（Cartier/劳斯莱斯）、头衔（董事长/SSS 级）堆身价。
- 每部剧配 2-3 个贯穿物件钩（泰迪熊/婚戒/金剑吊坠），承担伏笔—羞辱—反转认亲全链条。
- 敏感内容用"遮挡+合理化"机制（毯子、颠簸、晕车借口），让观众脑补而非直给。
- 台词按目标市场配语言对照（主力英文+中文，印度市场含印地语）。

## 核心认知框架（L5）

1. 剧本的第一受众是算法和付费墙，不是读者——前 3 秒定生死，付费墙先于剧情被设计。
2. 情绪配比 > 情节新鲜：虐在表层、爽在深层，积压越久释放越贵。
3. 信息密度是钩子的本质：30 秒塞三个信息点，三句话锁死全剧母题，慢热是原罪。
4. 人物用四状态定义（起点→转折→高潮→终点），各绑一个情绪关键词；反派是观众情绪的靶向标靶，也必须有完整弧线。
5. 每个剧本是可拆资产：换赛道、拆姊妹剧、换体量（精华版/漫剧/付费短篇），一个 IP 至少 3 种变现形态。
6. 物件是记忆的锚：台词会忘，物件不会。

## 视觉风格（L6）

- 文档纯文本、短行瀑布：动作一句一行、台词一人一行、场间空行，无长段落、无加粗、无配图。
- 场记行 `集-场 日/夜 内/外 地点 出场人物` 贯穿全剧；角色首登场给【字幕】身份卡（关系型角色标注关系）。
- 特写指令精确到器官（瞳孔/手/嘴角）；集尾三板斧=定格（+粒子特效）→黑场/闪白→未完待续字幕。
- 色彩是情绪编码：冷色=虐/现实，暖色=回忆/甜，金光=觉醒/身份揭示，血红=背叛开局；一个赛道一套主色。
- 强调的唯一手段是【字幕】大卡：身份、金额、反转词上字幕，等效于图文排版里的加粗标红。

## 冲突时的取舍顺序

1. 用户本次明确指令（题材、集数、平台、语言）
2. L2 中匹配当前体裁的结构模板（单集钩子和付费墙位置不可让）
3. L1 语言特征与 L6 格式规范
4. L3-L5 认知框架（决定母题与符号选择）

语料剧本的具体剧情、人名、台词不得搬进新剧本——复刻的是写法，不是内容。
