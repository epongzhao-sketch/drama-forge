# 文章结构模板

> L2 结构分析产物。语料是竖屏短剧剧本（单集约 1.5-2 分钟，全剧 27-96 集、中位数约 50 集），"文章结构"在此对应两层：**单集内部结构**与**全剧宏观结构**，另附语料中第三类文档"拆剧分析"的结构模板。

## 内容类型 A：单集结构（所有剧本通用）

**单集体量**：平均 2.2 场戏/集，约 2000 字符/集，英文台词约 20 行/集。

```
场记行（集-场 日/夜 内/外 地点 出场人物）
▲ 开场镜头（1-2 行动作，直接承接上集悬念，不做空镜铺垫）
第 1 个冲突回合（对白 3-6 回合，攻击—反击—升级）
▲ 动作转折（肢体冲突/物件出现/第三人闯入）
第 2 个冲突回合或新场景（信息加码，秘密泄露一半）
集尾钩（定格/黑场/闪白 + 一句中断台词或反转揭示 +【字幕：未完待续】）
```

铁律：
- **每集必须有集尾钩**。全语料 3420 集，集尾三类收法：①台词中断型（"我们的身份就是——"）；②表情定格型（"瞳孔地震，呆立原地"）；③新威胁登场型（红衣男子阴鸷注视）。
- **开场不铺垫**。第一行动作直接进入上集悬念的延续或新冲突现场，环境描写只在场景第一次出现时给 1 行。
- 单集只推进一个冲突单元，不并线。

## 内容类型 B：第 1 集结构（黄金开局，决定生死）

语料中所有剧本分析都用同一把尺子量第 1 集，四层钩子缺一不可：

```
前 3 秒视觉钩：一个反常画面（血/跪下/床/钱/怪物真身），不给解释
前 30 秒信息钩：连扔 2-3 个高密度信息点（身份反差、利害关系、隐藏威胁）
前 60 秒金钩：亮出全剧底牌或长线期待（重生闪回、隐藏身份、命中注定）
集尾痛点钩：一句内白/一个动作锁定全剧核心冲突，逼观众点下一集
```

两种开局骨架：
- **冷开场闪回式**（女频虐恋/奇幻主流）：先演结局级危机（跪银手铐、被刺穿胸）→ 字幕"X 年前/一个月前"→ 顺叙。代表：Rebirth From Betrayal、Awakened as a Dragon Tamer、Swapped to a Beggar。
- **VO 自我介绍式**（校园/都市主流）：主角 VO 三句定人设（我是谁+我多惨/多强+今天出了什么事）→ 冲突当场引爆。代表：I Accidentally Sexted My Enemy、Step Aside I'm the A+ Heiress。

## 内容类型 C：全剧宏观结构（以 50 集为基准）

### 付费墙与卡点

- 付费墙常规位置：**EP5 / EP12 / EP24 / EP38 / EP45-50**（ReelShort/FlexTV 系）。每个付费墙必须是大情绪点（当众羞辱、撕毁协议、身份揭晓、枪击复仇），强度要求 9/10 以上。
- 卡点密度曲线：**低开高走、每 5 集一个台阶**。EP1-5 每集 2-3 个小卡点铺情绪；中段 4-5 个/集；EP33 后付费墙密集连发。

### 情绪曲线（5 段式，全语料通用）

```
第一段 隐忍/紧绷（EP1-10%）：主角被压制，情绪关键词=心疼、愤怒
第二段 蒙冤/崩塌（10-25%）：误会加深、当众受辱，关键词=憋屈
第三段 觉醒/沦陷（25-50%）：主角拿到底牌（或主动沉沦），关键词=决绝
第四段 翻盘/沉溺（50-90%）：打脸连发、身份揭晓，关键词=爽
第五段 收束（90-100%）：复仇完成+新感情线/余韵/下一季钩子
```

### 分型骨架

**女频狼人/奇幻虐恋**（语料最大类，14+ 部）：被家族/命运辜负 → 觉醒血脉或隐藏身份 → 拒绝/离开 → 男方追妻火葬场 → 加冕/登顶。核心装置：Rejected Mate、Fated Mate、契约婚姻、血脉觉醒。
**男频扮猪吃老虎**（12 部）：主角"为爱/隐姓埋名放弃巨大既得利益"开局 → 被身边人联手欺压 → 底牌逐层揭开 → 当众打脸 → 登顶+新秩序。注意：开局必须有"主动放弃既得利益"的动作，否则隐忍没有说服力。
**18+ 擦边**（6 部）：封闭空间 + 禁忌身份 + 蒙在鼓里的第三方。单集循环"铺垫—接触—升级—差点被撞破—蒙混过关"，亲密层级按 手→口→身 逐段解锁，VO 占比可超 60%。
**校园甜宠/禁忌**：秘密（错发消息/继兄妹/暗恋）→ 秘密暴露 → 霸凌与维护 → 双向奔赴。节奏最快，冲突回合最短。
**家庭逆袭（中文原生本子）**：受辱 → 隐藏身份亲属亮牌 → 反派逐级加码 → 连环打脸。单集结构同上，台词全中文，情绪括号更密。

## 内容类型 D：拆剧分析文档（语料中 13 份，模板高度统一）

```
1. 基础信息：剧名/赛道定性/集数/单集时长/平台/人物表/核心反转/数据出处
2. 钩子拆解：2.1 前3秒视觉钩 / 2.2 前30秒信息钩 / 2.3 前60秒金钩 / 2.4 第1集结尾痛点钩（每条注明出处场次）
3. 付费墙与节奏：3.1 五大付费墙位置表（集数+事件+情绪强度打分）/ 3.2 卡点密度曲线
4. 人物与情绪：4.1-4.3 各主角弧线（起点状态→转折点→高潮点→终点状态）/ 4.4 情绪曲线（5段式）
5. 换皮方法论：5.1 可换赛道 / 5.2 同世界姊妹剧 / 5.3 换体量（压缩集数、漫剧、付费短篇）/ 5.4 换皮三关（骨架成立/融梗方法/文化适配）
6. 集纲：大期待/框架/核心梗 + 前10集逐集集纲（钩子/剧情/集尾悬念）+ 剩余集数延伸索引
```

写拆剧时每个判断必须标出处（场次号或"原剧 docx"页码），推断与实证分级标注（A 级原文实证 / B 级推断）。
