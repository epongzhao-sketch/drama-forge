# 视觉风格指南

> L6 视觉风格分析产物。说明：本语料是**剧本工程文档**而非图文文章——80 份 docx 中仅 1 份含 1 张图片，配图策略维度基本不适用。这里的"视觉"体现在两个层面：**文档排版规范**（剧本页面长什么样）和**镜头视觉指令体系**（剧本如何指挥画面）。

## 配图策略

- 语料近乎纯文本，无配图惯例。唯一一张图片出现在中文原生本《财神天降》中，属例外而非常规。
- 剧本的"图"全部由文字指令承担：【字幕】卡 = 屏幕文字层，【特效】= 视觉特效层，▲ 动作行 = 画面内容。复刻时不要在剧本里加图片描述或配图位，用这三类指令表达一切视觉意图。

## 排版格式

### 剧本页骨架（逐层缩进的四层文本）

```
剧名（文档首行，裸标题无格式）
# 第X集（集标题，全语料统一"第一集/第1集"两种写法，中文数字与阿拉伯数字均可）
1-1 日  内  冰球馆（看台/走廊/冰场）   ← 场记行：集号-场号 + 日/夜 + 内/外 + 地点
出场人物：A、B、C                        ← 人物行，可并入场记行尾部
▲ 动作/镜头描述（一句一行，一个镜头一行）
角色(情绪/动作): "English dialogue."（中文对照。）
【字幕: 角色身份卡/关键信息】（中文对照）
【特效: 具体特效描述】
```

### 格式细则

- **段落节奏**：全文无长段落。动作行 15-35 字一句一行；台词一人一行；场与场之间空一行。页面视觉上呈"疏密交替的短行瀑布"，任何超过 50 字的连续段落都是异常。
- **场记行格式高度统一**：`集-场`（如 1-1、10-3）编号贯穿全剧，时间词只用 日/夜/晨/昏，内外景只标 内/外，闪回直接写进场景位（`1-6 闪回 日 外 树林`）。
- **角色名首次登场必带【字幕】身份卡**：`【字幕: EVELYN CATIER】（埃芙琳·卡蒂尔）`，关系型角色标注关系（`【字幕：丹尼尔 (马修's sidekick)】`）。
- **台词行结构固定**：`角色名(括号情绪): "英文台词"（中文对照）`。情绪括号 2-6 字（冷漠/悲愤吼叫/压低声音/恶意冷笑），是演员表演指令，可叠加动作（`摇头，自我否定`）。
- **VO 标记**：`角色 vo:` 或 `角色 (vo):`，与现场台词严格区分。
- **加粗与标题**：剧本正文几乎不用加粗；拆剧分析文档用 `#` 编号标题（2.1/3.1/4.1 式层级），表格只用于付费墙位置和基础信息。

### 镜头视觉指令体系（剧本指挥画面的方式）

- **开场镜头**：俯拍/俯瞰全景 1 行定空间（"俯拍视角。一栋红色砖结构教学楼全景"），随即切特写。哥特式古堡、学院城堡、豪门别墅是女频奇幻的三大开场空间。
- **特写指令精确到器官**：瞳孔（金光/震颤/收缩）、手（攥紧/婚戒/按在合同上）、嘴角（冷笑/邪笑）。情绪必须翻译成可见的面部或肢体动作。
- **集尾视觉三板斧**：画面定格（+火花/金粉粒子）→ 黑场或闪白 → 【字幕：未完待续】。语料中绝大多数集尾遵循此组合。
- **特效词表**（高频复用）：瞳孔金光、雷电增强、画面定格、黑场转场、闪白、火星/金粉粒子、半透明特写层叠加、数据折线图浮现（SAT 成绩、资产数字）。特效永远服务情绪峰值，不做氛围装饰。
- **闪回的视觉标记**：冷色调/暖色调对切（现实=冷，回忆=暖），或字幕卡"Three Years Later"/"一个月前"。
- **擦边题材的视觉屏障机制**：毯子、后视镜盲区、车门——用遮挡物指令制造"窥视感"，让越界动作发生在画面可见与不可见的边界上。

## 色彩与强调

- 文档本身无彩色文字、无高亮块，黑白纯文本。
- "色彩"存在于指令层：冷色调=虐/现实，暖色调=回忆/甜；金光=血脉觉醒/身份揭示（狼人金瞳、财神金光、阿波罗日光法阵）；血红=背叛/命案开局。色彩是情绪编码，一个赛道一套主色（狼人=金+银，龙族=红+黑，霸总=冷灰+品牌金）。
- 强调的唯一手段是【字幕】大卡：身份、金额、关键反转词上字幕，相当于图文文章的加粗标红。
