# 爆剧复刻 · 爆款短剧节拍级复刻流水线

> 给一部爆款，还一部同骨架的新剧。复刻的是**核心期待、节拍节奏、情绪曲线**；新写的是**题材外皮、人物、场景、台词**。
> 产出语言：说明文字用中文，剧本台词英文（地道美式）+ 中文对照。

## 使用者须知

- 本流水线的大模型调用**全部消耗使用者自己的账号配额**（在哪位用户的 Kimi Code 里跑，就扣谁的）。
- 单方案完整剧本包是重产出（约 5-15 分钟），保持会话开启等待。
- 版权红线（不可违反）：**只镜像节拍功能与情绪曲线，禁止搬运原作的具体剧情、人名、场景设计与台词文本**。产出必须是法律意义上的新作。

## 输入要求

让用户提供：

1. **爆款剧本样本**（粘贴文本，越长越好；只有前若干集也可以）；
2. **红标素材段**：用户用【RED】…【/RED】标出投流数据最好的段落，或口头说明哪几集哪几段最爆；
3. （选填）新剧总集数（默认 60）、单集秒数（默认 75）、补充要求（如「偏女频复仇赛道」）。

拿到样本前不要开始拆解。

## 五阶段流水线

按顺序执行，每个阶段的**详细规格与输出模板**在 `references/` 对应文件里——进入该阶段前先读对应文件，不要凭本文件的记忆操作：

| 阶段 | 先读 | 做什么 | 产出文件 |
| - | - | - | - |
| 01 拆解 | `references/01-拆解.md` | 六板块拆解 + 红标段解读 + **逐集节拍镜像表** | `01-拆解报告.md` |
| 02 换皮方案 | `references/02-换皮方案.md` | 锁定核心期待，一次产出 10 个换皮方案 | `02-换皮方案.md` |
| — | — | **暂停，请用户从 10 个方案里粗选 3~5 个**，不要自作主张 | — |
| 03 地基 | `references/03-剧本包地基.md` | 每个入选方案：方向卡 + 人物小传 + 全剧集纲 | `03-<方案名>-地基.md` |
| 04 剧本 | `references/04-剧本正文.md` | 每个入选方案：3~5 集连贯剧本 + 2 集不连贯投流素材 + 逐拍镜像对照 | `04-<方案名>-剧本包.md` |
| 05 编审 | `references/05-编审判档.md` | 对每个剧本包判档（通过/附改法/重提/不通过） | `05-<方案名>-判档报告.md` |

所有产出写入当前目录下 `复刻项目-<项目名>/` 子目录。每个阶段完成后用一两句话告诉用户结果与下一步，等用户确认再继续下一阶段。

## 全程纪律（任何阶段不可违反）

1. **核心期待锁死**：拆解出的核心期待（观众为什么付费）是全剧地基。换皮只换元素外皮（黑手党/狼人/霸总/王室这类题材包装），核心期待一个字的方向都不能改——三道防线：方案锁定、剧本兑现、编审把漂移判为阻挡项。
2. **节拍级镜像**：新剧第 n 集的节拍数量/顺序/功能/情绪强度逐拍对齐拆解报告的逐集节拍镜像表；每集附「原作节拍 → 新剧落法」对照。
3. **全量欧美本地化**：禁中式人名/称谓/制度/场景（户口本→出生记录、高考→SAT、彩礼→婚前协议这类平移规则见 DNA 认知文档）；英文台词严禁中式表达。
4. **小黑DNA 阅读要求**：动手前按阶段要求读 `references/dna/` 下的蒸馏文档；规则冲突时优先级 = 用户明确指令 > 阶段规格 > DNA 结构规范 > 去 AI 味白名单。
5. **去 AI 味**：成稿按 `references/dna/less-ai-tone.md` 白名单清理，规则与 DNA 冲突时以 DNA 为准。
