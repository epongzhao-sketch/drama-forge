# 写作视角与认知框架

> L3-L5 分析产物。语料来源：海外竖屏短剧剧本团队（投稿找小黑）的 65 部剧本 + 13 份拆剧分析。这里的"选题"对应**赛道与题材选择**，"素材"对应**母题、装置与文化符号的选取**，"认知框架"对应团队对"什么是好剧本"的核心假设。

## 选题逻辑（L3）

### 赛道优先级

语料题材分布（一部剧可属多类）：婚恋 18、重生复仇 16、校园 14、狼人 14、都市霸总 12、家庭 7、成人向 6、神话/古装 6、人外/海洋奇幻 6、龙/奇幻 5、职业竞技 5、兽人 4、大码女主 4。受众结构：**女频 65 份、男频 12 份、BL/百合 3 份**——女频是绝对主力，男频做"扮猪吃老虎"单点突破。

选题判断树（从语料反推）：

```
这个题材在欧美/拉美/东南亚是否有已验证的对标爆款？
├─ 有 → 能否说出"我们多加了哪一层"？（复合母题：重生+调包+隐藏身份）
│   ├─ 能 → 立项（语料主流打法：成熟母题×2-3层叠加，不做纯原创）
│   └─ 不能 → 换皮：换人设关系/换场景/换文化符号，骨架不动
└─ 没有 → 除非单点极强（如"继母继子公路"的封闭空间设定），否则不碰
```

- **切入时机**：不追新题材，追"榜单已验证但还没被做烂"的题材。拆剧文档反复引用 ReelShort/DramaBox/GoodShort 周榜（"周榜第一""海外榜 4"）作为选题依据。
- **切入角度**：永远从"观众的爽点/痛点"视角切入，不从作者表达视角切入。每个题材先问"付费墙设在哪几集"，再问故事。
- **不写什么**：真实直系血亲禁忌、未成年性暗示（18+ 是底线）、没有付费墙落点的文艺向题材、单母题无叠加的平铺故事。

### 换皮三关（立项前自检，语料原文方法论）

1. **骨架成立**：核心设定必须有"硬支撑"——扮猪吃老虎要求主角开局主动放弃巨大既得利益；擦边剧要求封闭空间+强冲突+高频肢体接触三者齐备。
2. **融梗方法**：物件钩（泰迪熊/婚戒/花生过敏）可直接挪用；人物关系可替换变体（初恋→青梅竹马→战友→救命恩人），变体决定动机合理性。
3. **文化适配**：符号要贴合本地中产以上认知锚点——北美用集团+酒店+Cartier，拉美用家族农场+独立日+教堂婚礼，东南亚用家族企业+寺庙+金饰。

## 素材策略（L4）

- **素材来源**：以"成片转写"为一手素材（全剧汇总剧本即录屏拆分转写，文件中留有"录屏拆分可能有出入"的工作注记），以平台榜单数据为二手验证。不写没看过成片、只凭梗概的题材。
- **母题库依赖**：高度依赖已被市场验证的母题库——Rejected Mate、Fated Mates、契约婚姻、隐藏身份、重生复仇、错嫁调包、追妻火葬场、扮猪吃老虎、Step-family 禁忌。每个剧本 = 2-4 个母题的复合（如 Swapped to a Beggar = 重生复仇+调包+隐藏神祇身份+加冕）。
- **权威/可信度构建**：不靠真实考据，靠**符号密度**——金额（$2 million 赎金、$6B 投资）、品牌（Cartier、劳斯莱斯）、头衔（SVA 董事长、SSS 级御龙师）、数字（15 年、35 项专利）堆出"身价感"。数字必须具体，"很多钱"是废稿。
- **敏感信息处理**：18+ 内容用"遮挡物+合理化"机制（毯子作视觉屏障、颠簸作物理解释、晕车借口），让观众脑补而非直给；红线明确：不碰直系血亲、不碰未成年。
- **本地化素材**：台词按市场配语言对照（印度市场剧本含印地语对照，主力市场英文+中文对照）。

## 认知框架（L5）

团队对"好剧本"的核心假设，从拆剧文档反推的非显而易见命题：

1. **剧本的第一受众是算法和付费墙，不是读者**。前 3 秒决定生死，付费墙位置先于剧情被设计；"付费墙设在哪"是立项问题，不是后期问题。一切结构（卡点密度、5 段情绪曲线）都服务于"让观众在 EP5/EP12/EP24 掏钱"。
2. **情绪的配方比情节的新鲜重要**。他们不追求没人写过的故事，追求"虐与爽的精确配比"——"虐在表层（被讥讽、被驱逐），爽在深层（每一步让步都让最终反转加倍）"。积压越久，释放越贵。
3. **信息密度是钩子的本质**。前 30 秒必须同时塞进身份反差+利害关系+隐藏威胁三个信息点；"三句话锁死全剧母题"是开局合格线。慢热是原罪。
4. **人物弧线用四个状态定义，不用性格定义**。起点状态→转折点→高潮点→终点状态，每段绑定一个情绪关键词；反派也必须有完整弧线（入局→起势→暴露→崩塌），反派是"观众情绪的靶向标靶"，不是人。
5. **每个剧本都是可拆解的资产**。写完必问：能不能换赛道（男频改女频）、能不能拆姊妹剧（换视角/镜像剧/续集）、能不能换体量（30 集精华版/漫剧/Galatea 付费短篇）。一个 IP 至少拆出 3 种变现形态才算榨干。
6. **物件是记忆的锚**。泰迪熊、婚戒、金剑吊坠、粉色蝴蝶结内裤——每部爆款都有 2-3 个贯穿物件钩，承担"伏笔—羞辱—反转认亲"的全链条功能。台词会忘，物件不会。
